# A02 工具终局再认证局部验证

对应 [R2规范](../../system_dev/v26/04_tool_final_recovery.md)。从项目根目录运行：

```powershell
python verification/protocol_v26_final_recovery/run_all.py
```

`LATEST` 指向本次日志、结果及三个Profile的真实Ed25519签名样例。`red.txt`保留修复前两个恢复断言失败的记录；运行器继续检查这两个预期反例，不把它们计入通过测试。

R2的16项测试覆盖首次证明过期、换钥、同事实不同Ref、并发恰一次结算、失败终局释放、错误绑定、坏签名、缺记录、时间不确定、有效期上界、跨Profile、可信矛盾及HALTED不可自动解除。模型使用当前Schema、真实签名及严格验签；公开固定测试钥只用于复现。

验证范围是已领取操作的局部结算模型。C登记、认证控制快照、原派发见证与账本连续性是可信输入，未实现其真实核验。Ledger的执行/效果计数是预设事实，模型没有执行接口；因此只能验证再认证不改变这些计数，不能证明真实工具不会重复执行。持久事务、进程崩溃、跨操作effect_id/final_seq永久唯一性、全量迁移和产品实现均未测；模型只设置HALTED，未实现完整矛盾证据归档。本模型不替代39项语义用例及66项系统验收。
