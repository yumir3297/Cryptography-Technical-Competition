# 可选应用入口（IND V1）

从已认证业务提案构造原十字段 Action，并衔接外部真实批准与原 CommonW。

原 V1 接线、六字段来源和历史验证见[维护说明](../docs/final/trusted-action-resolver-v1.md)。后续统一服务的短期证明更新、角色、认证与白名单见[统一契约](../docs/final/unified-operation-contract.md)。

本机工业模拟器的固定配置启动入口为 local_runtime.py，见[部署与验收说明](../deployment/README.md)。HTTP 和 MCP 均为可选适配层；不要公开存储、编排或 W 对象的任意方法。一次性模拟引导及持钥审批/执行端不属于公开服务。
