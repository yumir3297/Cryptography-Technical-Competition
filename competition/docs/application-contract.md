# 比赛应用接口契约

当前参数、认证凭据、返回字段和重试接法以[内部接口对照](final/interface-reference.md)为准。这里说明接入原则。

应用挑战和本地投影使用比赛应用域；原 R2 Envelope、Record 与签名域按[消息合同](../../system_dev/v26/README.md)解析。两层对象不得混装。CommonW 未提供统一 Outcome，也未实现面向任意审计人的完整签名 STATUS/AUDITBundle。

接受事务先持久保存消费、稳定意图、资源和被冻结 Core，再由 X 签原回执。待签不是未接受；回执保存前不能领取。一次 EXEC 资格与实际发送分开计数，未知恢复只查原 attempt。状态读取本身不执行、不结算、不补签。

外部适配器负责会话认证、输入类型与编码校验和分支错误映射，不能暴露受信初始化、全 W counts 或测试故障开关。异常返回尤其不能直接推断接受未提交。
