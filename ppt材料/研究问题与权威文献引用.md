# ZJJ-CORE 研究问题与权威文献引用
整理日期：2026-11-24。用途：全国密码技术竞赛 PPT、作品说明书、答辩。本文为前期调研汇编；正式引用前应复核原文、版本及出版状态。以下中文均为概括而非逐字引文。

## 1. 研究问题与范围

面向高后果智能决策，Agent 的概率性决策及动态工具调用带来动作授权、连续状态约束和执行证据的可信性问题。ZJJ-CORE 研究在明确的信任假设下，如何通过密码学可验证授权、必要资源下限保持及原子接受，将动作从提出到最终接受关联为可独立复核的证据链。

不主张消除模型幻觉、不证明初始目标可达、不替 Agent 规划最优路线。必要资源下限由已定义且可验证的约束提供；保持必要条件不等于保证目标完成。原子接受也不自动等同于任意外部工具副作用的原子执行。

## 2. 统一参考文献与对应论点

### [1] OWASP GenAI Security Project. OWASP Top 10 for Agentic Applications 2026.
- 类型：行业安全风险指南，非正式标准。
- 官方链接：https://genai.owasp.org/top-10-for-agentic-applications-2026/
- ASI01 Agent Goal Hijack：目标可能遭劫持；ASI02 Tool Misuse and Exploitation：工具权限合法不意味着使用安全；ASI03 Identity and Privilege Abuse：身份与授权边界风险；ASI08 Cascading Failures：局部错误可能传播。
- PPT 建议：重点展示 ASI02、ASI08，引出动作级检查和连续状态约束。级联风险支持研究动机，但并不直接证明本项目的资源下限算法。

### [2] Debenedetti et al. AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents. NeurIPS 2024, Datasets and Benchmarks.
- 论文：https://arxiv.org/abs/2406.13352
- 类型：同行评审会议论文。
- 97 个任务、629 个安全测试用例（正式展示前以论文版本为准）。研究发现即使没有攻击，模型也无法可靠完成所有任务；工具返回的不可信内容还能引入间接提示注入风险。
- PPT 建议：说明安全问题并不局限于恶意攻击，不能仅依赖模型正确决策；任务失败本身不必然等于安全违规。

### [3] NIST. Announcing the AI Agent Standards Initiative for Interoperable and Secure Innovation. 2026-02-17.
- 官方链接：https://www.nist.gov/news-events/news/2026/02/announcing-ai-agent-standards-initiative-interoperable-and-secure
- 类型：美国国家标准与技术研究院标准化倡议公告，并非已发布的强制标准。
- 支持论点：智能体代表用户自主行动时，需要安全、身份、授权及互操作方面的规范研究。

### [4] NIST. Design Tenets for Agent Identity Management Systems. 2026-10-27（日期与标题以官网为准）。
- 官方链接：https://www.nist.gov/blogs/cybersecurity-insights/design-tenets-agent-identity-management-systems
- 类型：NIST 技术观点文章，非正式标准。
- 前期调研概括：以密码学建立可信边界，关注身份、授权、来源、信息、执行和动作之间的可验证关联。
- 项目映射：Ed25519 签名认证授权来源；哈希承诺与对象引用绑定任务、策略、动作及状态；执行证据与原子接受形成关联。上述映射为本项目设计解释，并非 NIST 对本项目的认可。
- PPT 建议：作为从 AI 安全问题过渡到密码学研究问题的关键材料。

### [5] Tether: Verified Stateful Policy Engine for System-Level Monitoring of Agents.
- 链接：https://arxiv.org/abs/2611.25599
- 前期调研记录：2026-11-19 公开预印本；作者、机构、日期及后续评审状态须复核。
- 支持论点：无状态策略检查难以覆盖某些跨步骤数据流与副作用；有状态策略及形式化安全不变量是相关研究方向。
- 既是研究背景也是竞品。不能据此宣称本项目首次提出有状态约束。

### [6] Google Cloud. Agent Payments Protocol (AP2). 2025.
- 官方链接：https://cloud.google.com/blog/products/ai-machine-learning/announcing-agents-to-payments-ap2-protocol
- 类型：产业协议及官方技术介绍。
- 支持论点：通过签名授权凭证关联用户意图、购物车和支付，提供可验证的授权记录。
- 项目映射：高后果动作的密码学证据绑定具有现实需求；AP2 聚焦支付，本项目拟面向可抽象的高后果动作。通用性及差异仍须实验与规范对比证明。

### [7] The Agent Action Decision Protocol (AADP).
- 链接：https://datatracker.ietf.org/doc/draft-saha-aadp/
- 类型：Internet-Draft，不是正式 IETF 标准；引用时须记录具体版本及日期。
- 前期调研记录：涉及动作授权、累积预算、原子资源预留及决策证据，具体语义须逐条核对草案。
- 属于重要竞品，应重点比较资源下限与累计预算的差别、授权和接受之间的状态绑定、执行证据的验证边界及并发语义。不得未经对比声称创新独占性。

## 4. PPT 推荐叙事

1. AgentDojo [2]：即使无攻击，Agent 也并非总能正确完成任务。
2. OWASP [1]：工具误用与级联故障说明局部权限控制不足。
3. NIST [3][4]：引出身份、授权与执行的密码学可信关联需求。
4. 项目问题：如何在不依赖 Agent 自身决策正确性的前提下，提供动作级可验证授权、必要资源条件保持和原子接受？
5. 相关工作：[5][6][7] 用于竞品比较；说明已有能力、项目边界以及尚需验证的差异。

示例：采购预算 100 万，连续支出 30、40、20 万后剩余 10 万；若已认证的后续必要资源下限为 25 万，则第三次支出应被资源约束拒绝。此为项目解释示例，不是文献实验结果，也不证明采购任务一定可达。

- 不将行业指南、技术博客、标准倡议或 Internet-Draft 称为已发布国际标准。
- 不将预印本称为顶会录用论文。
- 不把研究动机的外部背书表述为对 ZJJ-CORE 本身的认证。
