# AP2 adapter status

The native AP2 SDK was installed and its 188 tests were run (186 passed, 2
intermediate-hop failures). No live AP2 issuer/acquirer services or Gemini API
were available.

The capability matrix uses AP2's native SD-JWT/KB-SD-JWT chain, constraint,
recurrence and receipt tests. No ZJJ payment-mandate adapter was built; such an
adapter would be an additional protocol integration, not a claim that ZJJ
implements AP2.
